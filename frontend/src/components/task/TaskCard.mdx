# TaskCard

A single task card used in the dashboard's vertical list view. It shows the task title, a
status badge, and its meta (urgency, location, due date), tags, and assignees. The card links
to the task detail page.

## Default

A representative task with a short description, tags, and an assignee.

<Canvas of={TaskCardStories.Default} />

## Urgent

A high-urgency task (`urgency >= 4`) highlights its border in amber.

<Canvas of={TaskCardStories.Urgent} />
